目录职责、固定接口与实现边界

用于在多型号 MCU 之间快速迁移。业务层只面对稳定的 xhh_BSP 与 Components 接口；切换 MCU 时，只维护当前项目的 xhh_BSP 实现和 Platform 厂家库。

基准：SHS_136_BIG_New 当前结构与 trellis_spec 已确认规则。本文标注“固定”的内容必须保持一致，“按需”内容只在真实需求出现时创建。

适用范围

本规范管理的是 MCU 工程分层。它不规定具体产品算法、UI 页面、协议字段或 ADC 标定公式；这些内容按产品放在 Task 或 Component 中。
变化场景主要修改位置不应修改的位置
MCU、定时器、引脚、ADC 实体通道变更xhh_BSP/*.c、Platform/、工程配置xhh_Module 的业务算法与调用方式
产品功能、状态机、事件处理变更xhh_Module/厂家 HAL、寄存器、真实端口定义
通用 LCD、FIFO、CRC、协议实现变更Components/APP 中的业务调度

APP：唯一入口与调度层

固定APP/main.c 是应用入口。APP 负责调用 BSP 初始化、安装周期回调、启动业务 Cmd，并在主循环中处理周期标志和事件。APP 不承担某个外设的配置细节。

int main(void)
{
    xhh_BSP_SYS_Init();
    xhh_BSP_GPIO_Init();
    xhh_BSP_PWM_Init();
    xhh_BSP_SPI1_Init();
    xhh_BSP_ADC_Init();
    xhh_BSP_IWDG_Init();
    xhh_BSP_Timer_Init_1ms(APP_Timer_1ms_Callback);

    xhh_Task_Flash_Get_User_Data(...);
    xhh_Task_ALL_Cmd(1U);

    while (1)
    {
        /* 消费 1ms / 10ms / 100ms 周期标志。 */
        xhh_Event_Handle();
        xhh_SYS_Handle();
        xhh_Task_xxx_Loop();
    }
}
Task 不提供 Init、DeInit、Config。硬件初始化由 APP 直接调用对应 BSP 的 Init；Task 只使用已就绪的 BSP 接口。

xhh_BSP：固定接口与写法

固定BSP 的头文件提供跨 MCU 稳定接口；同名接口在不同 MCU 工程中都应能被 Module/Component 直接编译。真实端口、引脚、外设实例、Handle、DMA、厂商枚举和值只存在于对应 .c。

公共定义：xhh_BSP_Def.h

typedef enum
{
    xhh_BSP_OK = 0,
    xhh_BSP_ERROR_PARAM,
    xhh_BSP_ERROR_HARDWARE,
    xhh_BSP_ERROR_UNSUPPORTED
} xhh_BSP_Status_t;

XHH_BSP_NORETURN 用于标记不会返回的函数，并兼容 ARMCC、GCC、clang、IAR。所有 BSP 公共头均只 include 此文件，不能向上暴露 HAL 或厂商头。

系统：xhh_BSP_SYS.h

xhh_BSP_Status_t xhh_BSP_SYS_Init(void);
void xhh_BSP_SYS_IT_Disable(void);
void xhh_BSP_SYS_IT_Enable(void);
XHH_BSP_NORETURN void xhh_BSP_SYS_Reset(void);
XHH_BSP_NORETURN void xhh_BSP_SYS_ERR_Handle(void);
void xhh_BSP_Delay_ms(uint32_t ms);
  • xhh_BSP_SYS_Init 必须是第一个 BSP 初始化调用。
  • 项目内需要延时，一律调用 xhh_BSP_Delay_ms；仅 xhh_BSP_SYS.c 可以封装厂商 HAL_Delay。
  • IT_Disable 与 IT_Enable 必须成对使用，临界区只覆盖必要代码。
  • 固定参数错误、初始化失败、硬件通信超时调用 xhh_BSP_SYS_ERR_Handle，其内部为 while (1)。不自动复位，不提供默认参数或默认成功的 fallback。
  • xhh_BSP_SYS_Reset 只在业务明确要求复位时调用，不能作为 BSP 错误处理。

GPIO：xhh_BSP_GPIO.h

typedef enum
{
    xhh_BSP_GPIO_KEY_OK_PRESSED = 0,
    xhh_BSP_GPIO_KEY_UP_PRESSED,
    xhh_BSP_GPIO_KEY_DOWN_PRESSED,
    xhh_BSP_GPIO_CHARGE_FULL,
    xhh_BSP_GPIO_MOTOR_ENABLE,
    xhh_BSP_GPIO_HOLD_PP_ENABLE,
    xhh_BSP_GPIO_LCD_RESET_RELEASE,
    xhh_BSP_GPIO_LCD_DATA_MODE,
    xhh_BSP_GPIO_LCD_SELECT,
    xhh_BSP_GPIO_LCD_BACKLIGHT_ENABLE
} xhh_BSP_GPIO_Signal_t;

void xhh_BSP_GPIO_Init(void);
uint8_t xhh_BSP_GPIO_Read(xhh_BSP_GPIO_Signal_t signal);
void xhh_BSP_GPIO_Write(xhh_BSP_GPIO_Signal_t signal, uint8_t active);
void xhh_BSP_GPIO_Debug_Port_Set(uint8_t enable);

枚举值是稳定的逻辑信号名，不是端口、引脚或有效电平。Read 返回逻辑有效/无效，Write 的 active 也表达逻辑有效/无效；极性和初始电平封装在 .c。

ADC：xhh_BSP_ADC.h

typedef enum
{
    xhh_BSP_ADC_CHANNEL_0 = 0,
    xhh_BSP_ADC_CHANNEL_1,
    xhh_BSP_ADC_CHANNEL_2
} xhh_BSP_ADC_Channel_t;

void xhh_BSP_ADC_Init(void);
uint16_t xhh_BSP_ADC_Read(xhh_BSP_ADC_Channel_t channel);

固定CHANNEL_0/1/2 是逻辑槽位名，不是厂家 ADC 通道号。当前项目约定为：0=电池、1=充电检测、2=电流/触摸。迁移 MCU 时，由维护者在 xhh_BSP_ADC.c 将这些槽位映射为真实 ADC 通道。接口返回原始 ADC 计数；滤波、标定和单位换算放在 Task 或 Component。

PWM：xhh_BSP_PWM.h

void xhh_BSP_PWM_Init(void);
void xhh_BSP_PWM1_Start(void);
void xhh_BSP_PWM1_Stop(void);
void xhh_BSP_PWM1_Set_Duty(uint16_t duty_count);
void xhh_BSP_PWM2_Start(void);
void xhh_BSP_PWM2_Stop(void);
void xhh_BSP_PWM2_Set_Duty(uint16_t duty_count);

PWM1、PWM2 是固定接口槽位，不能改成 Motor、LED 等产品语义名。频率、ARR、定时器、通道和引脚只放 .c；Task 把业务值换算为 duty_count 后调用接口。非法 duty 或初始化失败进入 xhh_BSP_SYS_ERR_Handle。

SPI：xhh_BSP_SPI.h

void xhh_BSP_SPI1_Init(void);
void xhh_BSP_SPI1_Write_Byte(uint8_t data);
void xhh_BSP_SPI1_Write(const uint8_t *data, uint16_t length);
void xhh_BSP_SPI1_Write_Repeat(uint8_t data, uint16_t length);

SPI1 是固定接口槽位前缀。底层可用 DMA，但公共接口不能暴露 DMA Handle。LCD 的 CS/DC/RESET 是 GPIO 逻辑信号，由 LCD Component 使用 GPIO 接口控制，不归 SPI。

定时器：xhh_BSP_Timer.h

typedef void (*xhh_BSP_Timer_Callback_t)(void);

xhh_BSP_Status_t xhh_BSP_Timer_Init_100us(xhh_BSP_Timer_Callback_t callback);
xhh_BSP_Status_t xhh_BSP_Timer_Init_1ms(xhh_BSP_Timer_Callback_t callback);

只定义当前固定的 100us 与 1ms 节拍，不创建任意周期、硬件实例或运行时配置接口。中断回调只置位/计数，业务逻辑在主循环执行。当前 100us 可以是明确的未支持占位，返回 xhh_BSP_ERROR_UNSUPPORTED；1ms 应为真实实现。

其他当前固定 BSP

文件固定接口边界
xhh_BSP_IWDG.hInit、Refresh、DeInit当前 DeInit 为明确占位：PY32 IWDG 启动后不能可靠软件停止。
xhh_BSP_Power.hxhh_BSP_Power_Enter_Wake、xhh_BSP_Power_Enter_Sleep没有 xhh_BSP_Power_Init。硬件睡眠/恢复在这里封装，业务 Wake 状态/Event 仍属于 Module。
xhh_BSP_Flash.hErase、Read、Write地址是 MCU Flash 绝对地址；Erase 只擦一个硬件擦除单元，Write 不自动擦除。版本、CRC、冗余与磨损均衡由 Task/Component 管理。

xhh_Module：事件驱动业务层

xhh_Module/
|- xhh_Event/     xhh_Event.h / xhh_Event.c
|- xhh_Mode/      xhh_Mode.h / xhh_Mode.c
`- xhh_Task/      xhh_Task_<X>.h / xhh_Task_<X>.c、xhh_Task_ALL.h、xhh_Task.c

模块配置：xhh_Config.h

集中维护当前项目的模块阈值、极性、周期与标定表；业务分支只读取配置，不散落硬编码常量。

部分职责固定规则
Event定义业务事件，提供 xhh_Event_Trigger(event, parameter) 与 xhh_Event_Handle()。当前采用单槽事件，不在本规范中擅自改为 FIFO 或优先级位图。协议回调与 APP 不堆业务逻辑，转为事件处理。
Mode管理系统状态、模式状态与状态推进。不直接配置硬件；通过 Task 或 BSP 完成动作。
Task按产品域拆分：BAT、Key、Motor、UI、Flash、ADC、HoldPP、LED、Touch、TIMEOUT 等。Task 间允许互相调用。Task 不得依赖厂家库或真实端口。

Task 固定形态

  • 不创建 xhh_Task_xxx_Init、DeInit、Config。
  • 至少提供 xhh_Task_xxx_Cmd(uint8_t en)；需要周期处理时才提供 Loop。
  • 所有状态放在 .c 内的私有 static context，禁止公开可写全局变量。
  • Cmd 控制的 Loop 进入后先检查使能位，未使能立即 return，不操作硬件。
  • Process_10ms、Loop_100ms 等周期函数必须在头文件 Doxygen 注释中声明调用周期。
  • 标定表、阈值、极性、周期放入模块配置或私有配置区，不能散落在算法分支中。
/**

Components：可复用组件层

当前已有Components/LCD。组件必须具备跨项目稳定性，才值得进入 Components，例如 LCD、FIFO、CRC、RLE、协议、通用传感器驱动。

  • Component 只能依赖组件自身与 xhh_BSP 公共头；不得包含 main.h、xhh_Module、Platform 或厂家 SDK。
  • LCD 可以使用 xhh_BSP_GPIO.h、xhh_BSP_SPI.h、xhh_BSP_SYS.h。
  • LCD 进入休眠由 LCD Component 封装完整流程，例如背光关闭、Display Off、Sleep In，具体顺序以控制器手册为准；不能只关闭背光。
  • 只有本产品理解的 UI、Key、BAT、Motor 等，属于 Task，不因其使用某个外设就拆成设备型 BSP。

允许的占位函数

允许函数占位是为了不同 MCU 工程保持接口统一，但占位必须清楚、可审计，不能伪装为已支持功能。
  1. 头文件 Doxygen 明确写“当前为占位”、未实现原因和启用条件。
  2. 源文件函数体写 AI: 中文注释，说明原因、当前无动作和未来启用条件。
  3. void 占位不操作硬件；有状态返回值的占位返回 xhh_BSP_ERROR_UNSUPPORTED。
  4. 不得通过默认通道、默认 duty、默认成功等 fallback 掩盖未支持状态。

新增文件判定

问题答案放置位置
是否是 MCU 基础外设能力，且需要隐藏真实硬件？是新增或扩展 xhh_BSP_<Peripheral>.c/.h。例如 UART、I2C。
是否跨项目可复用，且不包含产品业务语义？是新增 Components/<Component>/。
是否属于本产品的状态机、控制策略、功能域？是新增 xhh_Module/xhh_Task/xhh_Task_<X>.c/.h，或扩展 Event/Mode。
是否只是厂家启动、系统、库文件？是放入/保留在 Platform/。
没有当前需求时，不建立空 BSP，也不为 Key、LED、Motor、BAT 建立 xhh_BSP_Key、xhh_BSP_LED、xhh_BSP_Motor、xhh_BSP_BAT。它们是业务域，使用 GPIO/PWM/ADC 等基础 BSP。

必须与禁止

必须

  • BSP 公共函数在 .h 与 .c 写 Doxygen。
  • 新增关键逻辑注释使用 AI: 中文格式。
  • 逻辑 GPIO 与逻辑 ADC 槽位只定义名称，映射值留在 BSP .c。
  • BSP 的 Handle、DMA、回调等状态使用 .c 私有 static。
  • 接口错误按明确策略处理，BSP 致命错误进入 xhh_BSP_SYS_ERR_Handle。
  • Task 周期接口在 Doxygen 中声明调用周期。

禁止

  • Module/Components 直接调用 HAL、CMSIS、厂家 SDK 或寄存器。
  • HAL_Delay 出现在 xhh_BSP_SYS.c 以外。
  • APP 或 Task 增加 GPIO/PWM Config、Task Init/DeInit。
  • Platform/Src 放项目手写的外设初始化、Handle、DMA、MSP 或 BSP 专属 IRQ。
  • 不支持参数时采用默认值、静默成功或其他 fallback。
  • BSP 错误路径调用 xhh_BSP_SYS_Reset。
